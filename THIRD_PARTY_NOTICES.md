# Third-party notices - Njordlinger (MO2 theme)

## "Skyrim" theme for Mod Organizer 2 - chintsu_kun (GPL-3.0)

`src\theme.qss.in` (and so the built `stylesheets\Njordlinger.qss`) is chintsu_kun's **Skyrim** theme, version 2.1.0
(https://github.com/nikolay-borzov/modorganizer-themes, GNU General Public License v3.0), with the Njordlinger
changes (dark mod rows, black separators, MO2's conflict highlight kept visible), every colour taken from a palette,
and icon rules added. The 35 images in `src\base\` are that theme's own widget art (checkboxes, radio buttons,
scrollbars, button borders, borders, separators, progress bar, slider); the built copies in `stylesheets\Njordlinger\`
are tinted from the palette (unchanged with the shipped palette).

## Icons

Drawn for this theme (`tools\icons.py`); no third-party icon art. The way MO2 themes set toolbar and button icons
(`#actionX` / `#listOptionsBtn` ... `qproperty-icon`) follows MO2's own convention, as the Paper and Dark Bronze themes
use it; no files of those themes are used.

## Mod Organizer 2

Theme selectors and the toolbar action names come from Mod Organizer 2 (https://github.com/ModOrganizer2/modorganizer,
GPL-3.0).
